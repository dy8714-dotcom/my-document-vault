# マイドキュメント保管庫 第3段階 (v3.0)

第2段階に加えて、以下の機能が追加されました。

## 第3段階で追加された機能

- ✅ **ファイル名変更**：セルの⋮メニューから名前を変更（Drive側も同期）
- ✅ **閲覧履歴**：閲覧したファイルを最新100件、タブから確認可能
- ✅ **プレビューモーダル**：セルをクリックするとDriveプレビューがモーダル表示。←→キーで前後移動
- ✅ **グリッドレイアウト**：サムネイル画像で並ぶ表示に切替可能（右上のボタン）
- ✅ **検索機能**：タイトル・メモをキーワード検索。「このタブ内」「全タブ横断」を切替可能
- ✅ **お気に入り**：⋮メニューから★お気に入りに追加。各タブの上部に固定表示
- ✅ **メモ機能**：セルごとに200文字までメモ。橙色のドットで表示
- ✅ **登録日/更新日切替**：ツールバーで日付表示を切替
- ✅ **PWA対応**：スマホのホーム画面に追加してアプリのように使える

## 使い方

### プレビュー表示
- セルをクリックすると、プレビューモーダルが開きます
- ←→キー、または画面上の‹›ボタンで前後のファイルを連続閲覧
- 「別タブで開く」ボタンで従来通り新しいタブで開けます

### レイアウト切替
- ツールバー右側の「☰」でリスト表示、「▦」でグリッド表示に切替
- 切替はブラウザに記憶されます
- グリッド表示ではPDF・画像・ドキュメントのサムネイル画像が表示されます

### 検索
- ツールバーの検索ボックスにタイトル・メモの一部を入力
- 「このタブ内」→現在のタブのみ検索、「全タブ横断」→4タブ全部を検索
- 全タブ横断検索は初回のみ全タブを読み込むので少し時間がかかります

### お気に入り
- ⋮メニューの「★ お気に入り」で追加
- 各タブの一番上に「★ お気に入り」セクションが自動表示
- 解除する場合も同じメニュー

### 名前変更
- ⋮メニューの「✎ 名前を変更」
- 新しい名前を入力して保存
- Google Drive上のファイル名も同時に変更されます

### メモ機能
- ⋮メニューの「📝 メモを編集」
- 200文字まで入力可能
- メモがあるセルには橙色のドット●が表示されます
- 検索対象にもなります

### 履歴タブ
- タブ列の一番右にある「🕐 履歴」タブから閲覧履歴を確認
- プレビューや「別タブで開く」で開いたファイルが記録
- 最新順に並び、最大100件まで保持

### 日付表示切替
- ツールバーの「登録日 / 更新日」セレクタで表示を切替
- Google Driveでファイルを更新すると「更新日」に反映されます

### PWA対応（スマホをアプリ化）
**iPhoneのSafariでの手順：**
1. Safariで https://dy8714-dotcom.github.io/my-document-vault/ を開く
2. 下部の共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択
4. 名前を確認して「追加」
5. ホーム画面にアイコンが並ぶ
6. アイコンをタップすると、Safariの枠なしでフルスクリーン起動

**Androidの Chrome での手順：**
1. Chromeで https://dy8714-dotcom.github.io/my-document-vault/ を開く
2. アドレスバー右のメニュー（⋮）→「ホーム画面に追加」or「アプリをインストール」
3. インストール完了

**PCの Chrome/Edge での手順：**
1. アドレスバー右端に「インストール」ボタン（⊕マーク）が表示されます
2. クリックしてインストール

## トラブルシューティング

### プレビューが表示されない
- ファイル形式によってはDrive側でプレビューできないものがあります
- 「別タブで開く」ボタンで開き直してみてください

### グリッドレイアウトでサムネイルが表示されない
- ファイルによってはサムネイルが生成されないもの（テキストファイルなど）があります
- Drive側でサムネイル生成に時間がかかる場合、しばらく待って更新してください

### 履歴が反映されない
- プレビュー表示するか、別タブで開くと履歴に記録されます
- 記録には数秒かかることがあります

### 検索でヒットしない
- 部分一致で検索します。ひらがな・カタカナは区別されます
- メモに書いた内容も検索対象になります
