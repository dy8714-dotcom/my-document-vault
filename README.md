# マイドキュメント保管庫 第2段階 (v2.0)

第1段階に加えて、以下の機能が追加されました：

## 第2段階で追加された機能

- ✅ **ラベル管理**：自由作成、編集、削除、色を10色から選択
- ✅ **複数ラベル対応**：1セルに複数ラベル付与可能
- ✅ **ドラッグ&ドロップ**：セルをラベル間でドラッグ移動
- ✅ **未分類セクション**：Drive直接追加されたファイルが目立つ色で自動表示
- ✅ **セル操作モーダル**：⋮ボタンから「開く / ラベル変更 / 削除」を選択
- ✅ **モバイル対応**：ログイン方式の改善、レスポンシブレイアウト

## 更新手順

GitHubに以下のファイルをアップロード（既存ファイルは上書き）：

1. `index.html` ← 更新
2. `style.css` ← 更新
3. `app.js` ← 更新
4. `config.js` ← 更新（フォルダID修正反映済）
5. `firestore.rules` ← 変更なし（そのまま）

**手順**：
1. GitHubの`my-document-vault`リポジトリを開く
2. 各ファイルをクリック → 鉛筆アイコン → 全削除 → 新しい内容を貼り付け → Commit

または、ファイルを一括アップロード：
1. リポジトリトップで「Add file」→「Upload files」
2. ZIPを解凍したフォルダの中身（README.md以外でもOK）をドラッグ&ドロップ
3. Commit changes

## 使い方

### ラベルの作成
1. 「+ ラベル追加」ボタンをクリック
2. ラベル名を入力（例：「仕事用」「投資用」）
3. 色を10色から選択
4. 「保存」

### ラベルの編集・削除
- ラベルセクションのヘッダー右の「編集」ボタンをクリック
- ラベル名や色を変更して保存
- 削除ボタンで削除（このラベルが付いていたファイルは未分類に戻る、ファイル自体は削除されない）

### セルにラベルを付ける
**方法A：ドラッグ&ドロップ**
- セルをドラッグして、別のラベルセクションのグリッドにドロップ
- 単一ラベルへの所属移動として扱われる

**方法B：ラベル選択モーダル（複数ラベル付け可能）**
- セルの右上の「⋮」ボタンをクリック
- 「🏷 ラベルを変更」を選択
- 複数のラベルにチェック → 「適用」

### 未分類セクション
- Driveに直接ファイルをドロップした場合、「⚠ 未分類（新規追加）」セクションに目立つ色で表示
- ドラッグして適切なラベルに移動

### モバイルでの操作
- セルの「⋮」ボタンをタップして操作メニューを表示
- ラベル変更は「ラベル選択モーダル」で複数選択可能
- ドラッグ&ドロップは画面が狭いため、モーダル経由のラベル変更が便利

## トラブルシューティング

### スマホでログインできない
- Firebaseのリダイレクト方式を使用しているので、ログイン後にページが自動で戻ります
- Cookieやセッションがブロックされていないか確認してください

### 認証エラーが出る
- 一度ログアウトして再ログインを試す
- スコープを変更したので、再ログイン時に「Driveのすべてのファイルへのアクセスを許可しますか」という新しい確認画面が出ます
